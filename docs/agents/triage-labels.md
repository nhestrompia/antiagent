# Triage labels

| Role | Local status | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate |
| needs-info | needs-info | More information needed |
| ready-for-agent | ready-for-agent | Specified for agent implementation |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Record the local status in the file's `Status:` line.
