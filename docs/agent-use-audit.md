The fresh raw pilot is retained in [pilot results](agent-route-layered-pilot-results.json). One noisy OCR match selected the wrong decision and another failed to locate a label. Neither error was relabeled as universal protection. The revised client requires exact normalized labels and retries fresh frame groups up to three times. Its final four-mode matrix completed all 12 cases without recorded errors.

My native-select actions used normal tool input; the final evaluation read diagnostics only after the action. The layered preview screenshot showed a black canvas and blocked state. My standard preview could not complete that application; the raw adaptive scripts could. These are different capabilities of the same agent workflow, not contradictory results.

Prioritize the surviving full-stack observation and trusted-input path first. Next review keyboard coverage, action-time checks, and the scope of renderer/DRM data exposure. Before release, test legitimate-human false positives and accessibility, add a real host-application integration, and rerun the strict zero-completion gate. None of the present audit outcomes authorizes an agent-proof package claim.

The native client used a new local-fixture tab and native screenshot/input/accessibility APIs. It opened no browser debugging connection; the preexisting profile was not attested free of every possible debugger. An isolated no-CDP launch could not be targeted through the available native app selector and was closed. Guest isolation reached mandatory search-engine setup, so a clean-profile native trial is not claimed. No browser preferences were changed during these measurements.

The first actual-Playwright setup tried to set a Runtime stack limit on a session that had not enabled Runtime; all three protocol errors are retained in `agent-route-playwright-pilot-results.json`. The final runner enables that session explicitly and records the full-stack blocked outcome. Neither setup failure nor an additional-session setting is represented as a successful framework bypass.
